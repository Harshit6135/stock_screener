Step 0 Kite Auth

  • Validates stored access_token.txt
  • Triggers login flow if token expired
  • Blocks all downstream steps on failure

Steps 1-3 Raw Data

  • Init: NSE/BSE CSV merge + yFinance enrich + Kite sync
  • MarketData: Daily OHLCV from Kite for all instruments
  • Indicators: pandas_ta studies (EMA, RSI, BBands, ATR, etc.)

Steps 4-6 Scoring

  • Percentiles: Cross-sectional factor percentile ranks
  • Scores: Weighted composite with penalty box
  • Rankings: Weekly average score → rank 1..N

📊 CSV Merge Logic

  • NSE: rename cols with NSE_ prefix

  • Output: ISIN, NSE_SYMBOL, BSE_SYMBOL, BSE_CODE, NAME

📡 yFinance Enrichment

  • Ticker priority: .NS → .BO (alpha) → .BO (code)

  • 3-tier NSE matching: Exact EQ → -BE suffix → hyphen-split
  • BSE fallback for NSE-missing stocks
  • Token cascade: updates market_data + indicators on token change
  • Series detection: EQ preferred over BE

🔍 Corporate Action Detection

  • Compares stored close vs fetched close for same date
  • Mismatch indicates stock split or bonus issue
  • Triggers full data refresh from earliest known date
  • Cascading delete: market_data → indicators

📦 Historical Chunking

  • Kite API limit: 2000 calendar days per call
  • Uses 1900-day chunks (safety margin)
  • Fetches backwards: latest → oldest
  • Deduplicates overlapping boundaries by date
  • Early stop if chunk returns empty (stock didn't exist)

🎯 Factor Scoring System FactorsService

Non-linear multi-factor scoring engine with 5 composite factors. Each factor uses domain-specific transformations (Goldilocks zones, RSI regimes, capped ratios) rather than simple linear scaling.

🌡️ Goldilocks Zones (Trend Distance)

  • 0–10% Building: score 70→85
  • 10–35% Sweet Spot: score 85→100
  • 35–50% Extended: score 100→60
  • >50% Overextended: decays from 60→0

📈 RSI Regime Zones

  • <40 Oversold: score = 0
  • 40–50 Building: score 0→30
  • 50–70 Sweet Spot: score 30→100
  • 70–85 Strong: score 100→90
  • >85 Overbought: floor at 60

⚖️ Factor Weights

  • Trend Strength: 30%
  • Momentum Velocity: 25%
  • Risk Efficiency: 20%
  • Conviction (Volume): 15%
  • Structure (Bollinger): 10%
  • Sum must equal exactly 1.0 (validated)

⚠️ Penalty Box Rules

  • ×0.5 Price below 200 EMA
  • ×0.7 Price below 50 EMA
  • ×0.8 ATR spike above 2.0
  • ×0.0 EMA 50 below ₹50 (penny stock)
  • ×0.0 Avg turnover below ₹0.5Cr
  • Penalties are multiplicative (can stack)

🔴 Sell Triggers

  • Stop-loss breach: current_price < stop_loss
  • Score degradation: score < exit_threshold (default 40)
  • Both checked for every holding each week

🟢 Buy Conditions

  • Not already held
  • Vacancy available (positions < max_positions)
  • Candidates ordered by score descending

🔄 Swap Logic

  • No vacancy but candidate beats weakest holding
  • Guard: candidate.score > swap_buffer × weakest.score
  • swap_buffer = 1 + config.buffer_percent (default 25%)
  • Generates paired SELL + BUY actions

🔺 Pyramid Add

  • Must be enabled via config flag
  • Current SL must be >= entry_price (profitable)
  • EMA 50 must be >= entry_price (trend support)
  • Uses pyramid_fraction of total capital for sizing

📐 ATR-Based Position Sizing

  • Fetch ATR(14) for prev_friday
  • stop_distance = ATR × sl_multiplier
  • risk_per_trade = total_capital × risk_percent
  • shares = risk_per_trade / stop_distance
  • Capped by remaining_capital & max_position_pct
  • Hard SL = stop_loss × (1 - hard_sl_percent)

🔄 Vacancy Backfill

  • After all BUY decisions processed
  • If open_slots > 0 and remaining_capital > 0
  • Fills from top-N ranked list in order
  • Skips already-bought and held symbols
  • Reason tagged as "vacancy backfill"

🛡️ Stop-Loss System Multi-Layer SL

Three-layer stop-loss protection: weekly SL check (via TradingEngine), close-based daily SL (end-of-day), and hard SL (intraday low breach). Each layer has different trigger conditions and execution timing.

Layer 1 Weekly Stop-Loss

  • Checked in TradingEngine.generate_decisions()
  • Uses Friday close price vs trailing SL
  • Sell executed at Monday open
  • Also triggers on score degradation

Layer 2 Close-Based Daily SL

  • check_daily_stoploss() in ActionGenerator
  • Runs Mon-Thu (Friday handled by weekly)
  • Sell dated D+1 (next open execution)
  • Can trigger mid_week_buy to fill vacancies

Layer 3 Hard SL (Intraday)

  • Backtesting only (no live intraday data)
  • hard_sl_price = SL × (1 - 3%)
  • Executes at min(daily_low, hard_sl_price)
  • Same-day approve + process cycle
  • Skips symbols with pending close-based sells

📊 FIFO Trade Matching

  • Each SELL matched to earliest unmatched BUY (FIFO)
  • Handles partial fills across multiple buy lots
  • Shared utility between live journal & backtesting
  • Produces MatchedTrade objects with full PnL breakdown

📈 XIRR Calculation

  • Capital events as negative cashflows (outflows)
  • Current portfolio value as terminal positive cashflow
  • Uses Newton-Raphson method for IRR
  • Returned as annualized percentage

🔄 Trailing Stop-Loss

  • calculate_effective_stop() shared with backtester
  • new_stop = current_price - (ATR × sl_multiplier)
  • Only ratchets up: max(previous_stop, new_stop)
  • Mid-week: carries forward existing SL unchanged
